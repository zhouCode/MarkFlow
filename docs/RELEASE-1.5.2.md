## MarkFlow 1.5.2

本次更新重点修复课堂演示中的误编辑、快捷键和文档状态问题。

- 关闭窗口、退出应用或安装更新前，未保存的文档会提示“保存 / 放弃修改 / 取消”。取消另存为或保存失败时保留文档。
- Present 模式阻止格式命令、撤销、粘贴和替换修改讲义，同时保留查找、复制和导航。
- 修复标题、斜体、行内代码、列表快捷键；完善搜索面板的打开、替换和关闭操作。
- 修复跨目录切换讲义时图片缓存串用，以及撤销历史影响其他文档的问题。
- 修复网页内容获得焦点后，切换讲义、定位地址栏和关闭标签页的快捷键失效。
- 修复带文件参数启动、上次文档恢复及首次显示教师备注时的初始化问题。

验证：类型检查、生产构建及 44 项 Windows Electron 回归测试通过。安装包由 GitHub Actions 分别构建 Windows x64 和 macOS ARM64 版本。
